### Endpoint cần cover

| Path | Method | Function |
|---|---|---|
| `/api/v1/cart` | GET | `getCart` (existing) |
| `/api/v1/cart` | DELETE | `clearCart()` |
| `/api/v1/cart/items` | POST | `addToCart(payload)` |
| `/api/v1/cart/items/{itemId}` | PUT | `updateCartItem(itemId, payload)` |
| `/api/v1/cart/items/{itemId}` | DELETE | `removeCartItem(itemId)` |

`updateCartItemSchema`: `{ quantity: number().min(1).max(99) }`.
